# 产品设计

## 定位

一个轻量的 macOS 菜单栏工具。用户对屏幕上的信息 Ping 一下，选择想做的事，核对任务卡，交给已配置的 Agent 推进。

App 保存来源、确认内容、关联任务和推进细节。复杂推理、代码修改和测试由 Codex / WorkBuddy 承担。

第一阶段面向个人开发者：macOS、微信、一个执行器。

## 核心动作

| 默认动作 | 意图 | 默认输出 |
|---|---|---|
| 分析一下 | 理解消息和上下文 | 事实、判断、疑问、下一步 |
| 拆成任务 | 将讨论变成工作项 | 目标、依赖、验收标准；默认本地草稿 |
| 开始处理 | 根据明确需求推进实现 | 代码改动、验证、结果 |
| 继续推进 | 为已有关联任务补充证据 | 新增信息差异、后续执行 |

每个动作有稳定 ID、显示名、图标、内置提示词、提示词版本、默认执行器及确认策略。显示名和提示词可配置，不用显示名充当动作标识。

默认四个动作；意图库支持增删、搜索、排序和编辑名称、图片、行为与提示词。轮盘最多启用 8 个动作，按启用数量等分，从上方顺时针排列；可全部移出轮盘。新动作使用 UUID 身份，默认仅播放特效。触发方式支持 Option（Alt）/ Ctrl / 鼠标右键拖动 / 自定义快捷键，默认仍为 Alt。

可设置新意图默认图片、上传自定义图片，以及独立设置轮盘中心图片和恢复默认。中心仍为取消区。删除动作不修改已有任务快照；重新新增不会复用已删除动作 ID。

提示词组成：

1. 用户配置的动作模板。
2. 用户本次补充说明。
3. 来源与上下文材料，明确标记为引用数据。
4. 执行范围、输出要求。

变量只支持白名单，例如 `{{source.app}}`、`{{source.message}}`、`{{context}}`。不支持 shell 展开、任意代码执行或隐式加载文件。原型使用纯文本，不实现变量解释器。

模板变更仅影响新草稿。已有草稿保留快照，可通过明确的“更新为最新模板”动作修改；已提交轮次不可变。

## 交互流程

1. 键盘模式按下触发键时冻结目标窗口身份和指针原点；右键模式保留按下坐标，拖动超过阈值后确定该坐标下的目标窗口。
2. 展示轮盘；指针进入动作区域给出高亮，回中心或 Esc 取消。
3. 松手，播放对应 Ping 图标的弹出、扩散与淡出动画，同时保存原始截图与动作；捕获进度独立显示在图标下方，屏幕底部时移至上方。捕获结束不提前打断动画。
4. 结合窗口身份、OCR / AX 信息和渠道检索定位真实消息。
5. 展示确认卡：来源、目标消息、上下文范围、动作、执行器。
6. 用户确认，生成不可变提交快照，写入派发队列。
7. 原位反馈“已交接”；任务面板跟踪执行，完成时展示产物。

截图必须排除自身轮盘，并保留捕获坐标系、屏幕缩放与窗口边界。系统权限只在启用相应功能时引导申请。

消息定位有歧义时展示候选；找不到时保留截图分析，但不能伪装成已找到会话。用户翻到历史消息时，不能默认按今天查询。

## 确认方式

首版统一“松手捕获，点击提交”，不在松手瞬间执行外部任务。

确认卡主按钮随状态变化：

| 状态 | 主操作 |
|---|---|
| 新草稿 | 确认提交 |
| 相同草稿再次 Ping | 打开原确认卡 |
| 已排队 / 执行中 | 查看进度；可暂存补充 |
| 已完成，存在新材料 | 确认补充并继续 |
| 结果未知 | 核对交接状态 |
| 无新材料 | 查看已有结果 |

Esc 关闭确认卡但保留草稿；“取消草稿”才取消本次意图。关闭界面不等于取消执行器任务。

将来可允许“分析一下”等低影响动作启用自动交接，但必须预先配置；默认不启用。误触撤销只在尚未派发时有效，已交接任务的取消取决于执行器能力。

## 信息结构和视觉

采用石墨灰背景、金色强调和系统字体；金色问号作为应用标识。界面固定深色以匹配轮盘，使用原生控件、清晰的导航层级和操作状态。

- 菜单栏：捕获入口、最近任务、设置。
- Ping 轮盘：最多 8 个启用动作、中心取消区。
- 确认卡：来源证据 → 执行意图 → 执行器 → 确认。
- 历史面板：原始记录、逐轮推进细节、产物链接。
- 设置：动作模板、渠道连接、执行器、保存策略。

窗口内演示仍保留；第一期 B 已增加独立桌面浮层和截图来源复核页。

## 成功标准

- 用户明确知道本次 Ping 产生了草稿还是已经派发。
- 多次 Ping 不会静默创建重复外部任务。
- 执行器收到的材料能追溯到原始消息。
- 新信息可以续接已有任务，历史提交不会被覆盖。
- 空闲状态不持续截图、不启动 CLI 轮询。

## 第一期 B 已实现的桌面入口

“桌面 Ping”页提供辅助功能/屏幕录制状态及启用开关。当前可选择 Option（Alt）、Ctrl / Control、鼠标右键拖动或自定义快捷键：按住并移动显示轮盘，松手触发所选意图。回中心或 Esc 取消；键盘模式也可右键取消，右键模式可左键取消。单修饰键模式下，普通组合键取消轮盘并继续传递给原应用；自定义模式接管配置的组合键。浮层不抢焦点；截图完成后打开来源复核页。

来源复核页同时展示截图、原始指针、OCR 线索、会话候选、日期范围和消息搜索结果。默认最近 30 天只是检索范围，可改历史日期；没有唯一消息证据时不会静默绑定。用户确认候选，或明确保留截图来源后，才能进入已有的提交确认流程。真实来源可在确认后提交 Codex CLI；虚构练习仍使用模拟执行。

轮盘使用灰金色扇区与 lolPing 素材。截图和证据仅保存本机，默认不上传；删除任务会清理独占截图。

### 最新意图规则
项目选择已移除，重复任务按来源、动作 ID 与执行器识别。每个动作独立选择任务或仅特效；仅特效松手时播放图标与扩散淡出，不生成截图、草稿或外部任务。意图模式变更只影响后续 Ping，不改变历史任务。删除本地记录不等于远端取消。

## 应用页面（已实现）

- 桌面 Ping：开启全局手势、预览已启用意图、查看最近任务；捕获后在原页面核对截图和微信来源。
- 任务记录：按全部/待确认/其他筛选，搜索意图、会话及正文；详情提供编辑、模拟提交、取消和删除。
- Ping 意图：左侧选择动作，右侧配置名称、任务/纯特效行为及提示词，并可预览特效。
- 微信连接：配置本机 wxview，检查连接，查询会话与消息并手动选为来源。
- 设置：触发键、系统权限、本地数据和执行器接入状态。虚构消息交互练习放在设置底部，不作为默认入口。

窗口标题与主界面不显示“原型”标签；本地模拟提交与未接入执行器仍在相关操作处明确说明。首次打开默认进入桌面 Ping。

### 鼠标右键拖动

设置中可选择“鼠标右键拖动”，与 Alt / Ctrl 模式互斥。按住右键移动超过 10 点，轮盘以按下位置为锚点出现；继续移向意图，松开右键触发。回中心、Esc、左键、其他按键或滚轮取消，取消后松开右键不弹菜单、不触发任务。普通右键点击（含阈值内轻微移动）在松开时补发原按下事件再传递松开事件，因此菜单在松开时出现。带修饰键的右键操作沿用原应用行为。本模式接管右键拖动；需要应用原生右键拖动时选择键盘模式。切换方式不改变已有任务或自动提交规则。

### 自定义键盘快捷键

Option 与 Alt 为同一按键。除原有单独 Option / Control 外，可录入一个含 Control、Option 或 Command 的组合键（可叠加 Shift），按物理键码与完整修饰键组合匹配。录入期间暂停新手势，Esc 取消录入；配置存入本机偏好，不改任务数据。按住组合键后移动选择，先松开主键触发；提前松开修饰键、其他按键或鼠标点击取消。忽略主键重复按下，取消后需松开主键才能开始下一次。启用全局 Ping 后接管所配置组合键，其他快捷键继续交给原应用。
